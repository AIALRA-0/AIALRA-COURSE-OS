# 备份与恢复手册

## 1 备份范围

常规备份包含 PostgreSQL 中的运行与学习状态、ReadWeave 权威数据、原始材料、正式发布、必要配置，以及 Course OS 数据卷中的已确认阅读副本。阅读副本是 ReadWeave 内容的持久化投影，用于确认后的读取和来源短暂不可用时的只读降级；它不取代权威备份。

缩略图、临时转换物、构建产物和可再生缓存不进入常规备份

## 2 保留策略

- 7 个每日增量快照
- 4 个每周增量快照
- 6 个每月增量快照
- 每月在空环境执行 1 次恢复演练

## 3 恢复与回滚

应用回滚时恢复先前的运行环境、Compose 配置和保留的不可变镜像。回滚不得删除、覆盖或重置数据库、ReadWeave 权威备份、已确认阅读副本或其恢复点；继续遵守 7 个每日、4 个每周、6 个每月快照的保留策略。若应用回滚后数据不可用，使用已核验的数据库、ReadWeave 和 Course OS 数据卷备份恢复。

## 4 恢复验收

- 第一项，在隔离空环境恢复数据库和 ReadWeave
- 第二项，恢复 Course OS 数据卷中的已确认阅读副本，以及内容寻址存储中的原始材料和正式对象
- 第三项，核对 ReleaseManifest 哈希和页面来源哈希；确认 `/healthz` 报告进程存活，且有确认数据时 `/readyz` 报告阅读就绪
- 第四项，启动不连接模型提供商的播放器
- 第五项，恢复原学习位置、问答、测验、错因和复习队列
- 第六项，记录恢复时长、失败对象和校验摘要

只看到备份任务成功不算恢复通过；必须从空环境读回课程并继续学习

## 5 发布要求

备份任务成功不等于恢复通过。每个部署环境必须为精确应用提交记录最近一次空环境恢复证据、恢复时长、对象哈希和可用回滚点；公开源码仓库不保存真实备份位置、主机路径或生产恢复记录。
