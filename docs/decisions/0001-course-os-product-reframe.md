# ADR 0001：Course OS 产品重定义

## 1 决定

状态：已采纳

日期：2026-08-28

Course OS 定义为以不可变来源、机器可检查解释覆盖、形成性测验和长期掌握记录为核心的课程学习编译器与播放器

第一生产版本服务 1 个可信用户，保留 `workspace_id`、`actor_id` 和版本字段，为多用户版本留下兼容边界

## 2 权威边界

- ReadWeave 保存正式课程语义、来源锚点、讲解、问答、测验、错因、掌握状态、审核和发布版本
- Course OS 负责任务编排、文件处理、质量门、临时会话、播放器和部署
- PostgreSQL 保存上传、任务、租约、重试、事件和事务外发箱
- 内容寻址存储保存原始文件、页面栅格和媒体字节
- ReleaseManifest 固定一次发布使用的全部来源、讲解、测验、策略、模型和质量版本

Course OS 只能通过版本化 HTTP 接口访问 ReadWeave，不得直接读取或修改 ReadWeave 数据库

## 3 发布门禁

- Gate 0 至 Gate 10 全部通过后，才能标记个人生产版本 `1.0`
- 高风险解释元素覆盖率必须为 100%，一般必需元素覆盖率不得低于 98%
- LaTeX 严格解析失败时阻止发布，不能退化成普通文本
- 发布对象不可原位修改，任何内容变化必须创建新草稿和新发布
- 50 页质量型生成的硬预算为 8 美元，达到 80% 时停止非必要阶段，达到 100% 时停止新的模型调用
- 备份必须在空环境完成恢复演练

## 4 被拒绝方案

不把 Course OS 全部写入 ReadWeave 单体，也不把 OpenMAIC 作为主项目分支

单体方案会把材料转换、任务重试、缓存、部署升级和许可边界耦合到笔记系统，故障范围和维护成本过大

## 5 许可与公开边界

ReadWeave 继续遵守 `AGPL-3.0-only`

Course OS 按 Apache-2.0 方向准备，但公开发布前必须重新核验依赖许可、课程版权和第三方资产授权

公开仓库不得包含 EE680 原始材料、学习记录、私有路径、生产域名、密钥或生产配置
