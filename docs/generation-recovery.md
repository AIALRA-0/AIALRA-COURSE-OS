# 教学生成恢复现状

## 当前执行路径

每页先理解来源，再形成简短教学计划、生成完整教学页、检查最终格式，必要时最多执行一次局部格式修复。内容质量评价用于离线审读，不阻断线上交付。逐行覆盖证明、多阶段正文生成和多轮语义修复已退出当前主路径

任务记录保留已完成页、失败页、费用和事件。页面草稿写入 ReadWeave 后会读回核对；只有读回成功，页面才计入完成。失败页可以单独重试，已完成页不会因同一任务恢复而再次生成

## 进程中断与重启

生产 API 在开始监听前取得独占写入锁。重启时，它将遗留的 `running` 任务重新排队，由现有 Worker 派发；新领取会递增租约的 fence token，使旧执行者不能提交结果。执行循环跳过任务记录中已经完成的页面

取消的任务不自动恢复。已经完成的页面保留原草稿和完成记录；失败页面使用现有重试接口定点处理。恢复测试覆盖“第一页面已完成、第二页面未完成、旧租约尚未过期”的情况，断言重启后只调用第二页面

## 尚不能保证的边界

如果外部模型已经接收并计费，但 API 在费用或页面完成状态持久化前中断，恢复时可能重新发起该页请求。租约隔离可以阻止旧执行者写入过期结果，却不能撤销外部供应商已经收取的费用；当前实现不能承诺这种窗口下绝不重复扣费

真实供应商故障、ReadWeave 短暂不可用以及 API 或 Worker 中途重启仍需要在有可用教学线路时做端到端故障实验。单元测试通过不代表 100 页真实生成已经完成稳定性验收

## 历史记录

旧版曾有四页因覆盖引文、规划字段或数学格式问题失败。那些中间正文当时没有保存，不能从历史任务恢复。旧版的阶段检查点与字段修复单不再描述当前线上教学生成主路径；研究历史问题时应以对应旧提交和事件为准
