# 教学部件复用与验收边界

## 固定主链

页面理解 → 简短规划 → 一次完整教学包 → 最终交付格式检查 → 必要时一次局部格式修复 → 保存并可读

承上启下后补，不阻塞主体；教学质量评价留在离线，不加入覆盖证明或语义阻断

## 替换与移除

- 合并主模板与代码里重复的教学指令，保留一个教师模板、现有最终格式合同及四份完整写作技能
- 移除“可见矩阵最多转写两个例值”的输入限制，保留清楚可读的来源数据，无法辨认的局部标明不确定
- 移除视觉输入中文字层的固定截断，本页来源原样传入；邻页来源另放 `courseContext`
- 移除文字层缺失时把旧生成讲解混入来源的回退，原图转写才是图像页的事实输入；旧讲解只留在离线质量对照中
- 移除“课件可能有错也不得说明”的冲突要求，保留原件并解释可直接复算的差异
- 不采用上游 JSON 修复器，现有解析器已有同类能力；不为复用而再添一个解析层
- 不采用 ClassBuild HTML、脚本和第二套渲染器

## 来源与教学计划

`source` 是本页文字层及视觉转写；`courseContext` 是材料目录及相邻页文字层；`teachingPlan` 仅安排讲述顺序

邻页上下文由已上传的来源构建，无需等待邻页模型生成；旧版生成的讲解不作为邻页来源事实

本页数字、表格值和连接关系只能来自本页来源；背景知识与演示数值必须明确用途，不能伪装成原图观察

## 已观察到的来源故障

伪代码页的嵌入字体使文字层出现乱码，矩阵页的数值则仅存在于图像中；这两类页面必须把原图实际送入已有视觉识别接口，不能把旧教学正文当作提取结果

伪代码缩进曾被视觉模型错读，进而改变循环范围；运行镜像加入 Tesseract，仅在已有页面理解步骤内提供 OCR 行的实际横向位置参考，不创建新业务阶段或教学覆盖义务

此参考最多等待八秒，识别程序不可用或输入异常时返回空参考，原来的视觉读取继续执行；位置参考只进入视觉读取，不直接传给正文生成，识别字符仍需与原图区分

页面理解优先检查设置中已配置的 extract 模型，再使用现有可用视觉线路；主教学模型仍按已有教学路由选择，不因视觉线路选择而切换

位置参考改善输入，但不证明视觉模型永远识别正确；真实来源对照和教学核读保留在离线验收中，不加入在线语义门禁

## 恢复与学习交互

草稿写入或立即读回发生可重试的短暂连接错误时，在现有保存操作内重试一次，继续使用原幂等键、内容和执行围栏；认证或版本冲突不自动重试

不同学习 session 的未完成页面与视图更新分别保存，切换课程不会把旧课程的页面位置写到新课程；旧更新完成后只更新对应存储，不覆盖当前页面

显式页面链接优先于上次后台任务入口；学习 session 创建失败仍保留已打开的讲解，显示失败反馈；ReadWeave 窗口在点击时打开，获取有效链接后导航，失败则关闭空窗口

## 可验证证据

真实生成对照保存于私有 `var/eval`，包含来源、发送的提示词、模型原始结果、整理后的教学包、时间和成本

生产日志仍只记录安全的运行元数据，不记录密钥、完整响应或私有课件

单元测试证明输入分离、来源不截断和调用边界；真实生成与浏览器阅读证据另外保存，不能用构建成功代替

实际学习质量由来源核读与用户阅读共同判断；结构校验通过不能冒充用户接受
