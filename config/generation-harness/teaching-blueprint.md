# 逐页教学蓝图

这不是给学习者看的说明，而是生成器必须遵守的讲解顺序

## 讲解流程

1. **先说这页要解决什么**：用一句话说明问题、目标和读者学完后要能完成的动作
2. **先读原对象**：按页面出现的顺序识别文字、公式、图形、表格、代码和它们的连接关系，只写来源中能直接确认的事实
3. **解释核心关系**：说明对象之间如何作用，按因果或执行顺序展开，每一步只承担一个任务
4. **做一个可复算或可复现的例子**：保留页面给出的数值、变量、条件和结果，写出关键中间步骤
5. **说明边界与易错点**：明确适用条件、不能推出的结论、特殊情况和失败条件
6. **最后回收**：用一小段把“对象—关系—结论—下一步”连起来，不重复前文

## 覆盖方法

- 每个 atom 先分配给一个主要讲解位置，coverageEvidence 只记录该位置和真实 atomId
- 一个 atom 的多个字段必须在同一处连续解释，不能用空泛的“已覆盖”代替内容
- 已经在原对象段解释过的内容，后文只能引用，不得整段改写重复
- 题目必须分别检验一个关键对象、一个关键关系、一个边界或条件和一个可复算结果；题干不能只是正文换词

## 输出边界

- 学习正文不出现“页面元素核对”“来源状态”“等待审核”“模型推断如下”等流水线标签
- 来源事实、外部背景和推断可以用一次简短的小标题区分，但不得在每个列表项重复声明
- 证据、模型、成本、策略和失败原因写入元数据与 Studio 检查器，不写进学习者正文
- 不添加与理解、判断、计算、行动、边界或下一步无关的装饰性句子
