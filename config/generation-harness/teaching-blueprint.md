# 自适应逐页教学蓝图

本蓝图只约束生成器的内部决策，不规定学习者最终看到的固定章节

## 内部流程

1. 确认这页要帮助读者解决的问题和可验证学习结果
2. 按页面自然顺序识别全部有效对象，并排除纯装饰、重复页眉页脚和无法辨认的内容
3. 为每个对象补齐最小必要前提，再解释对象之间的因果、约束或执行关系
4. 材料包含计算、抽象机制或多步操作时，提供可复算或可复现的完整示范
5. 材料包含条件、否定、范围、例外或失败风险时，在首次使用的位置说明影响
6. 仅在内容复杂到需要回收时总结，且不得重复正文

## 页面类型

- cover：短讲课程或材料身份、主题范围和阅读入口
- agenda：说明主题顺序、分组和依赖
- concept：从问题出发解释定义、作用、机制和适用条件
- formula：保留公式并解释变量、单位、条件、步骤和结果
- diagram：保留图形阅读顺序，解释节点、连接、方向和限制
- table：保留表头、行列、单位和数值，解释比较关系与异常
- code：保留代码或伪代码，逐行解释状态变化
- mixed：按原对象出现顺序组织多个媒介

## 覆盖与去重

- 每个 atom 只分配一个主要讲解位置，后续需要引用时不重复整段
- coverageEvidence 只记录真实 atomId、真实字段和可定位正文证据
- mainContentMarkdown 与 fullExplanationMarkdown 承担不同职责，不得逐条互抄
- 题目检验理解和迁移，不得只把正文换成问句
- 没有来源支持的例子、数字、历史、应用、边界和英文名称不得生成

## 学习正文边界

- 不出现资源包、需求包、规则包、蓝图、模型、成本、哈希、审核和覆盖状态
- 不出现固定流程标题或装饰性说明
- 原始对象由 Course OS 页面左侧保留，右侧讲解从“怎样看”和“说明什么”开始
- 内容规模服从当前页面，不用统一字数和统一章节数量冒充质量
