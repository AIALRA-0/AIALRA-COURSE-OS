# 自适应逐页教学蓝图

本蓝图只约束生成器的内部决策，不规定学习者最终看到的固定章节

## 内部流程

1. 确认这页要帮助读者解决的问题，以及读者需要先理解什么；只有会改变当前结论的明确适用边界才进入计划，没有时留空
2. 按页面自然顺序识别全部有效对象；纯排版资源只有在来源结构、样式与上下文共同证明用途时才不另设教学内容，原件及资源记录保持完整，角色不明与加载失败的对象不擅自排除
3. 为每个对象补齐最小必要前提，再用一个分段清楚的完整讲解按“具体对象→对象关系→必要机制”解释因果、约束或执行关系；章节之间逐步增加新信息，不重复完整定义
4. 材料包含计算、抽象机制或多步操作时，提供可复算或可复现的完整示范
5. 材料包含条件、否定、范围、例外或失败风险时，在首次使用的位置说明影响
6. 在完整讲解后用 2 至 5 个简短列表项压缩核心关系，不添加第二个总标题，不重述定义、推导或示例

## 页面类型

- cover：短讲课程或材料身份、主题范围和阅读入口
- agenda：说明主题顺序、分组和依赖
- concept：从问题出发解释定义、作用、机制和适用条件
- formula：保留公式并解释变量、单位、条件、步骤和结果
- diagram：保留图形阅读顺序，解释节点、连接、方向和限制
- table：保留表头、行列、单位和数值，解释比较关系与异常
- code：保留代码或伪代码，逐行解释状态变化
- mixed：按原对象出现顺序组织多个媒介

## 覆盖与去重

- 每个 atom 只分配一个主要讲解位置，后续需要引用时不重复整段
- 缺失清单和证据边界属于内部核对信息；只有具体缺口会改变当前理解时，才在相关结论旁简短说明，不把“本页没有……”作为默认内容
- 先验知识定义必要前提，完整讲解推进本页知识，总结压缩结果，易错点辨析具体误解，承上启下连接相邻页面；跨区只引用已讲内容并说明当前用途，不完整复制
- coverageEvidence 只记录真实 atomId、真实字段和可定位正文证据
- fullExplanationMarkdown 是唯一完整讲解；mainContentMarkdown 只放在它后面作为高层总结，不得逐条互抄
- 前页来源存在且相关时才写承上启下，前页事实和本页问题分开；先验知识只选必要术语，逐项使用经核对的中英文名称与连续的五段逻辑定义
- 题目检验理解和迁移，不得只把正文换成问句
- 没有来源支持的例子、数字、历史、应用、边界和英文名称不得生成

## 学习正文边界

- 不出现资源包、需求包、规则包、蓝图、模型、成本、哈希、审核和覆盖状态
- 不出现固定流程标题或装饰性说明
- 原始对象由 Course OS 页面左侧保留，右侧讲解从“怎样看”和“说明什么”开始
- 内容规模服从当前页面，不用统一字数和统一章节数量冒充质量
