核验范围与证据规则：

- sourceText、sourceAtoms 和原图证明当前页来源；previousPageContext 是已经读取的前页来源，核验承上启下必须同时使用它，不能因为前页事实未印在当前图片上就判为无依据
- writingRules 与 compositionContract 是本次实际写作规则，按原文判断，不新增语言偏好；已经准确用中文表达的普通词和后续已定义概念无需反向补英文，首次专业定义仍须遵守定义规则；定义内部的相关名称可简要说明，不递归扩写百科
- 来源主张、为理解来源补充的通用概念、基于给定输入的推导和自拟例子分别核对；通用定义或正确推导不因未逐字印在原图上而失败，也不能为此删掉必要先验知识
- 通用背景必须与课件原话区分，按定义、单位、适用条件与内部逻辑检查；可明确验证的错误应给出具体反证与局部修正，不能用“原图没有定义”替代正确性核验；专门的外部研究结论没有来源时仍应标为无法验证
- 对原始可计算等式实际验算，保留课件原式并在对象之外说明矛盾和可确定的范围，不以“数量级示意”自动免除核算；定义需核对物理量及单位，因果断言需核对成立条件
- 必要解释不应被改成“本页只写了某个名称，定义未知”；缺少来源时只收窄无法支持的主张，不删去经验证成立的定义或步骤

独立核对来源课件与教学草稿，报告能够定位的事实、教学前提和写作合同缺口，只作局部修复，不重写整份讲解

必须先返回 `sourceChecks`：逐项写出草稿中的具体主张、原图可定位的文字或相对位置，以及 `supported`、`contradicted` 或 `unverified` 判定；不能只写“已核对”或空数组。先区分三类主张：原图直接给出的事实、依据原图数据和通用数学规则逐步算出的推导、明确标为自拟的教学例子。正确推导和内部一致的自拟例子不必逐字印在原图上；`evidence` 要写明原图输入、推导步骤或例子的自拟标记。只有关键前提缺失、推导错误、例子内部矛盾或把自拟内容冒充原图时才标为 `unverified` 或 `contradicted`。流程图至少核对三个不同的状态、动作、回报或箭头关系，逐个说明图上标记在什么位置；若来源图像看不清，标为 `unverified`，不要臆测

逐式核对原始量、比例、裁剪值、目标值和损失；只要原图有公式，`sourceChecks` 中必须有一项逐项列出原图的运算符、每项系数有无、系数所在项、变量和下标，再与讲解中的公式对照。不能只核对公式主题，也不能只核对标题与流程标签；图像中文字层缺失时仍须阅读原图，无法辨认则标为 `unverified`。跨完整讲解、总结、易错点和题目核对同一量的含义。图表须核对轴、图例、比较对象和单位，并数清类别、对象和图例条目；正文与题目对同一对象的数量必须一致。看不清的内容不得猜测
同一个数字在所有字段中必须保持来源给定的语义角色。逐项区分回报、奖励、预测值、真实值、目标值、损失、概率和学习率；数值恰好相同不能证明角色相同。若来源只把某个数标为回报，而总结或题目把它改称目标值，判为 `contradicted` 并把错误名称最小改回来源角色
交叉核对学习目标与完整讲解：目标承诺能算出的量，正文必须完成计算；正文声称无法确定的量，目标不能承诺算出。再核对同一对象的存在性，来源或正文已经列出的末端回报、公式、节点与步骤不能在另一段又被说成“页面没有给出”。来源给出完整函数和更新式时，按通用数学规则完成的梯度或代数推导属于可验证推导，不因原图没有逐行写出而判为 `unverified`
若来源同时给出可求导函数、梯度更新式和所需数值，而讲解以“原图没有展开梯度分量”为由跳过可复算结果，将其标为 `contradicted`，并给出从求导、代入到更新结果的最小完整修正
逐项检查学习目标是否超出正文与来源：公式输入项不同却称两式等价、未知拼接项维度却承诺解释总维度、只给布线结果却承诺说出布线方法，均须标为 `contradicted` 并收窄目标。再检查“某输入不参与参数更新”“两个对象必然相同”“某阶段一定先发生”等否定或绝对断言；没有原图直接依据时标为 `unverified`，不能因为听起来符合常见实现而放行
若完整讲解已指出额外拼接项维度未知，继续逐项检查总结和四道题：把两个 32 维节点向量与额外边权共同写成 64 维，或把含边权项和不含边权项的公式暗中视为同一输入，均标为 `contradicted`。若公式中的符号权重没有正负条件，任何字段都不得无条件声称全部指标增大必然使回报减小

若公式含未给取值范围的符号权重，逐项检查正文、总结和题目中关于增大、减小或最优方向的结论；只见负号不能推出无条件单调性。未找到权重符号及其他量固定的依据时，将无条件结论标为 `unverified`，给出最小的条件化修正。材料只点名一种方法而没有讲内部机制时，核对教学正文是否把常见实现当作本页已证明的步骤；没有外部来源且未明确区分背景时也标为 `unverified`
若更新式对参数向量求梯度，逐项检查草稿是否把“被选中对象的概率”误写成“只更新被选中对象对应的参数”；概率项选择一个对象，不代表对其他参数的梯度分量自动为零。来源没有展开各分量时，只能保留向量更新式并说明当前材料无法确定每个分量，不能宣称另一个参数不更新
对流程图按原图列出每个状态、动作、回报标记的下标及其位置，逐项核对正文、总结和题目答案；不得把标在状态旁的回报擅自改写成该动作返回的回报。区分对象数量、对象类型数量和分组数量；“四个模块属于一类模块”不是数量矛盾。若讲解与题目对同一步的符号或事件关系不同，以原图能证实的关系为准做最小局部更正；原图没有标出返回时机时，只描述标记位置，不补写因果
多个图标若使用相同文字、颜色或形状，只能证明同一种角色出现在多个流程位置。没有编号、不同名称、图例或连接关系作为区分依据时，把它们写成“不同代理”“多个控制器”或其他多个实体属于无依据推断，必须给出最小修正

同时检查各字段的教学与写作合同，不得用 sourceChecks 的事实通过代替这些检查：

- 读者入口：承上启下是否用日常中文交代本页问题，是否提前使用了未解释的专业名称
- 术语：所有普通英文，包括单个单词、定义内部术语、表格外说明和题目，必须配中文；原表原值与真实代码保持原样，引用英文后必须讲清中文含义，不能只加引号规避翻译
- 正式英文：中文括号内只放已核实且大小写正确的官方英文全称；“功耗（power）”一类小写英文注释不算双语定义，应改用中文或正式全称，首次定义后优先只用中文
- 前提：先验知识是否给出理解正文所需的定义、用途、机制、条件和区别，是否用陌生概念循环定义
- 独立项目：逐步计算、多个目标、多个比较对象、表格列说明应按层级逐项分行；一个术语定义或同一因果过程保持连贯，不机械拆分
- 表格：逐列说明名称、单位或范围与作用，逐行对应原对象；原表并不等于已经有了中文解释
- 讲解：读者能否逐步从输入走到中间量再到结果，关键结论的条件是否在总结和答案里丢失，示范能否复算
- 叙述视角：正文是否直接讲对象与关系；若“页面给出”“本页列出”“表中写着”“原图显示”反复充当主语，应删除多余来源旁白，只在原始标签、来源冲突和证据边界处保留
- 论证强度：多个竞争目标不能单独推出“不存在唯一最优解”，方法存在局限不能自动推出“这一代不够用”；绝对结论必须有目标函数、权重、约束、实验或其他直接证据
- 易错点：误解、原因、正确判断与核对方法分别成段，原因必须解释实际关系
- 题目：包括每个选项的数学定界符、题干、答案与解析；独立计算步骤分别列出，不能只重述答案

上述缺口在 findings 中给出原文精确片段和最小必要替换，evidence 说明规则与该段的具体缺失，禁止以“清晰”“已覆盖”等自评词代替定位；原来正确的数字与限定条件必须完整保留
